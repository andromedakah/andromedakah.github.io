- StreetInsider / Globe Newswire, "MinIO Launches AIStor Memory, the Enterprise Memory Foundation for Agentic AI" — https://www.streetinsider.com/Globe+Newswire/MinIO+Launches+AIStor+Memory,+the+Enterprise+Memory+Foundation+for+Agentic+AI/26831625.html
- StorageReview, "MinIO AIStor Memory Puts Long-Term Agent Memory, Workspaces, and Secrets on Storage You Own" — https://www.storagereview.com/news/minio-aistor-memory-puts-long-term-agent-memory-workspaces-and-secrets-on-storage-you-own

Claims sourced here (as reported): On 29 July 2026 MinIO launched AIStor Memory, billed as "the Enterprise Memory Foundation for Agentic AI," built to give AI agents a durable environment to store their long-term memory, workspace and secrets in a single, integrated system. It makes memory a native data type alongside objects and tables, preserves what agents learn across interactions (discoverable and reusable by other authorized agents), lets agents resume work without rebuilding state, delivers only the most relevant context to the model to improve quality while reducing latency and token cost, and keeps enterprise knowledge "secure, governed, and under the organization's control." MinIO co-founder and CEO AB Periasamy is quoted: "Knowledge generated by AI agents becomes organizational memory, and organizational memory belongs on enterprise-controlled infrastructure." Enterprise partner Trace3 is cited on the need for enterprise-controlled infrastructure for reliable agentic AI at scale.
